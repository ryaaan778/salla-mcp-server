Claude Desktop Setup

Add the following to your claude_desktop_config.json file:

{
  "mcpServers": {
    "salla": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://salla-mcp-server.inlustris.workers.dev/sse"
      ]
    }
  }
}
Restart Claude Desktop after saving the config.
